PROHOME BACKEND API TZ

1. Umumiy ma'lumot

Base URL:
- Loyihada controller prefiksi yo'q.
- Misol: /auth/login, /users/me, /apartments

Auth:
- Protected endpointlar uchun header:
  Authorization: Bearer <accessToken>

Token response formati:
{
  "user": {
    "id": 1,
    "phone": "+998901234567",
    "firstName": "Ali",
    "lastName": "Valiyev",
    "role": "USER",
    "regionId": 1,
    "createdAt": "2026-04-02T10:00:00.000Z",
    "updatedAt": "2026-04-02T10:00:00.000Z"
  },
  "accessToken": "jwt_access_token",
  "refreshToken": "jwt_refresh_token"
}

Pagination query:
- page: number, default 1
- limit: number, default 10, max 100

Paginated response formati:
{
  "data": [...],
  "meta": {
    "page": 1,
    "limit": 10,
    "total": 100,
    "totalPages": 10
  }
}

Enumlar:
- UserRole: SUPERADMIN, ADMIN, USER
- OtpPurpose: REGISTER, LOGIN
- BannerLocation: HOME_TOP, HOME_MIDDLE, HOME_BOTTOM, OTHER
- LayoutStatus: AVAILABLE, SOLD_OUT, COMING_SOON
- ApartmentListingType: SOTISH, IJARA, SHERIK_KERAK, ALMASHISH
- ApartmentDealStatus: ACTIVE, SOLD

Validation va xatoliklar:
- 400: noto'g'ri body/query/param yoki validation xatolari
- 401: token yo'q, noto'g'ri yoki eskirgan
- 403: rol yoki ownership yetarli emas
- 404: obyekt topilmadi
- 409: duplicate telefon, duplicate rating, duplicate profile kabi holatlar

2. AUTH API

2.1 POST /auth/send-otp
Description:
- Telefon raqamga OTP yuboradi.

Access:
- Public

Body:
{
  "phone": "+998901234567",
  "purpose": "REGISTER"
}

Response:
{
  "message": "OTP yuborildi"
}

2.2 POST /auth/register
Description:
- OTP va parol bilan yangi user ro'yxatdan o'tadi.

Access:
- Public

Body:
{
  "phone": "+998901234567",
  "firstName": "Ali",
  "lastName": "Valiyev",
  "password": "strong-password",
  "otp": "123456",
  "regionId": 1

- Token response formati qaytadi.

8. Tavsiya etiladigan front ishlatish tartibi

Oddiy user flow:
1. /auth/send-otp
2. /auth/register yoki /auth/login
3. accessToken ni saqlash
4. /users/me orqali profil olish
5. /master-profiles yoki /apartments yoki /ratings bilan ishlash

Master bo'lish flow:
1. /job-categories dan category list olish
2. User formni to'ldiradi
3. /master-profiles POST qilish

Apartment yaratish flow:
1. /regions dan region list olish
2. /apartment-categories dan category list olish
3. Kerak bo'lsa /complexes va /apartment-layouts dan list olish
4. /apartments POST qilish
5. Sotilganda /apartments/:id/status ga {"dealStatus":"SOLD"} yuborish

Company flow:
1. Admin /companies POST bilan company yaratadi
2. Company owner login bo'ladi
3. /complexes va /apartment-layouts endpointlari bilan o'z obyektlarini boshqaradi
